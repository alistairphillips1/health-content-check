# Your content production process

One page. Fill it in once, then follow it. Keep it where the people who write content can see it.

This is the thing a certification scheme actually assesses. Any single page can be tidied up after the fact. A process is what makes the next fifty pages good, and it is the only part of this that compounds.

Copy the block below, answer every line and put a date on it.

---

**A note on honesty.** If a line above is not true yet, write what is actually happening rather than what should be. A process document describing a fiction is worse than no document, because it will be believed. Write the real one, then improve it.

**If you later apply for certification.** Schemes assess the process, not the page, and they will ask for evidence that these lines are lived. Start the log now: a simple sheet of what was published, when, who checked it and when it is next due, is worth more at assessment than any single polished document.
