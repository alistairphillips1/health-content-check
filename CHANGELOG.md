# Changelog

Dates matter here. These guides describe menus in Claude and ChatGPT that change
without notice, and the standards behind the checklist are revised periodically.
If the newest entry below is more than about six months old, treat the install
steps with suspicion and check the live help pages.

## 1.1.0, 2 September 2026

Added the routes that need no Claude account, and one for Gemini.

- The one-page checklist, as a printable PDF and as markdown. No AI needed.
- The paste-anywhere prompt, about 400 words, for any chatbot with no setup.
- Install guide for Gemini, using a Gem. Gems verified free on every Gemini plan,
  web app only, on 2 September 2026.
- ChatGPT guide now states on page 1 that the reference-checking script cannot run
  there, because the Python sandbox has no internet access. The same limit applies
  to Gemini.
- All four PDFs are now generated by guides/build_guides.py, so one edit plus
  ./build.sh regenerates the set.

## 1.0.0, 2 September 2026

First public release.

- Skill: SKILL.md, the criteria gate, the improvement playbook and the production
  process template.
- Install guides for Claude and for ChatGPT.
- Standards checked on 2 September 2026: NHS digital service manual Standard for
  creating health content, the 10 published PIF TICK criteria, WCAG 2.2 AA.
- Install steps checked on 2 September 2026 against the Anthropic and OpenAI help
  centres. ChatGPT Skills availability was limited and in flux at that date, so the
  ChatGPT guide uses a Project as its main route.

Report anything that has drifted: https://github.com/alistairphillips1/health-content-check/issues
